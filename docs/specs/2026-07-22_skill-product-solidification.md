# Skill Product 固化规格

日期：2026-07-22

## 目标

给定一个已注册 Skill，YiW 可以生成一个适配该 Skill 的完整产品草稿。用户预览并确认后，产品进入侧边栏，拥有独立页面、专属会话和稳定的后端运行逻辑。

## 验收条件

- [x] Agent 能通过 `ui_skill_product_draft_create` 从 Skill 创建产品草稿。
- [x] 产品支持多页面和产品内导航，不限制为表单页面。
- [x] 产品至少包含一个可持续对话的 `AgentWorkspace`。
- [x] 安装版本保存 Skill 指令、工具、运行类型和项目范围快照。
- [x] 快照有 SHA-256 指纹，运行前重新校验。
- [x] 原 Skill 被编辑后，旧产品版本仍运行旧快照。
- [x] 产品会话绑定用户、模块、版本、Skill binding 和项目。
- [x] 产品会话与普通 Agent 会话隔离，本地缓存清空后可从服务端恢复。
- [x] 项目型产品在创建和每次运行时检查当前项目成员关系。
- [x] 产品运行时不能切换到其他提示型 Skill。
- [x] 产品模式不暴露 `use_skill`，工具白名单不能通过清空当前 Skill 绕过。
- [x] 工具调用继续受 `allowed_tools` 和现有审批控制。
- [x] 写入/执行型 Skill 固定使用交互确认模式。
- [x] 草稿继续经过检查、预览、权限确认和事务安装。
- [x] 产品可以随模块版本升级和退回。
- [x] 前端通过已有 Agent Stream 显示思考、工具、确认、结果和错误。
- [x] workflow Skill 通过固化 workflow 适配器执行并保留 JSON 输出合同。
- [x] 多页面分别保留自己的初始数据和动作结果。
- [x] 后端模块与 Skill Product 测试通过。
- [x] Renderer 类型检查、测试和生产构建通过。

## 失败处理

- Skill 不存在、未启用或需要项目但未给项目：拒绝创建草稿。
- Skill 没有明确 `allowed_tools`：拒绝固化，避免生成边界不清的产品。
- service Skill 没有已注册的专用 handler：拒绝固化；已有 `query_agent` handler 可以固化。
- 草稿中的 `bindingId` 不属于当前用户或当前草稿：检查失败。
- 页面 `AgentWorkspace` 与产品 binding 不一致：检查失败。
- 产品版本、权限、项目或会话不一致：运行失败并要求刷新或重新安装。
- Skill 快照指纹不一致：停止运行，不使用可能被改写的内容。
- Skill Product 草稿移除或替换绑定：检查失败，不能降级成普通模块安装。
- 幂等键被不同 Skill、项目或模块重复使用：返回冲突，不返回另一份旧产品。
